## 📂 Projects

### 🦠 [THE MALWARE CHRONICLE](./THE%20MALWARE%20CHRONICLE/)

**A Comprehensive Historical Archive of Computer Viruses & Malware (1971-2025)**

An educational web archive featuring a retro CRT terminal aesthetic, documenting 84 historic malware cases spanning 54 years of computer security history.

**Key Features:**
- 84 documented malware cases with full historical context
- Retro green phosphor CRT terminal design
- Decade-based navigation system
- Wikipedia-sourced references for educational purposes
- 31 individual year pages with detailed malware information

**Tech Stack:** HTML, CSS, JavaScript, Node.js (for utilities)
